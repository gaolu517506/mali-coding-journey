# 教师笔记 · 会聊天的码力（2 课时全集）

> 面向授课教师。学生视角见 [README.md](./README.md)；每课代码见 `lessonN_*/` 各 step 文件注释；完整成品见 `会聊天的码力-展示版.py`。

## 1. 三维教学目标（分课）

| 课时 | 知识 | 能力 | 情感 |
| --- | --- | --- | --- |
| 1 · 唤醒艾芯 | HTTP 请求与 API 概念、messages 三种角色、system 消息、temperature、大模型 = 文字接龙原理、幻觉与知识边界 | 把"调 AI"去魅成"发请求拆回信"；用实验探边界（控制变量意识） | 第一次让真 AI 回话的惊奇；建立"AI 会犯错，重要的事自己查"的清醒认知 |
| 2 · 性格说明书 | 提示词三要素（角色/口头禅/边界）、messages = 外置记忆、token 与计费常识、迭代式提示词工程 | 写可验收的说明书（测试题先行）；用失忆实验验证假设 | "我能定义一个 AI 的性格"的创造者身份感 |

**课纲关键词**：AI 对话 · LLM · 提示词工程 · 大模型 API —— 学生版 README 首行可见。

**贯穿心智模型**：AI = 超级文字接龙玩家 + 每次通话都重读全部聊天记录。这两个模型能解释本站几乎一切现象（为什么有性格、为什么会失忆、为什么按字数计费）。

## 2. 环境准备（⚠️ 本站有网络与 key 要求，课前必查）

## 3. 每课结构与卡点急救

### 第 1 课 · 唤醒艾芯（lesson1_唤醒艾芯/）

**节奏（90 分钟）**：故事一拍 3′（卫星投下艾芯）→ 演示展示版 5′（"两节课后你的艾芯长这样"）→ 跟做 40′（step1 离线版 → step2 真通话 → step3 接龙原理）→ 自主改造 20′（step4 换人设）→ 展示互评 15′ → 钩子 5′（"一句话能换性格，那一整份说明书呢？"）。

**急救表**

| 现象 | 原因 | 一句话修复 |
| --- | --- | --- |
| `ModuleNotFoundError: No module named 'requests'` | requests 没装 / 装错环境 | Thonny 包管理器装；确认用的解释器是 Thonny 自带 |
| 回信是 `401` / `invalid api key` | key 错 / 环境变量没生效 | 重配环境变量后**重开 Thonny**（环境变量启动时才读） |
| `Connection error` / 超时 | 机构网络禁外网 | 教师热点或投屏演示；step1 离线版保底 |
| `KeyError: 'choices'` | 返回的是错误 JSON | 打印 `r.json()` 看真实报错信息再对症 |
| 艾芯回复特别慢 | 免费模型高峰期排队 | 正常现象，正好讲"AI 也要排队"；耐心等或错峰 |

**话术**：API = **挂号信**（地址 API_BASE、门票 key、信件 messages）；system = **写给 AI 的说明书**（观众看不到但它必须守）；文字接龙 = **看前文猜下一个字**（温度低 = 只选最稳的，温度高 = 敢选冷门的）；幻觉 = **不知道也硬接**（接龙机器人的职业病）。

**课堂组织**：step1→step2 的"规则版 vs 大模型"对比是本课的灵魂演示——先让学生把离线版问到词穷（"它好笨"），再跑真 API（"它怎么什么都会"），落差即教学。

### 第 2 课 · 性格说明书（lesson2_性格说明书/）

**节奏**：钩子回收 3′ → 跟做 45′（step1 三要素 → step2 记忆/失忆实验——本站最大哇点）→ 自主改造 25′（step3 迭代 V1→V2）→ 毕业作品 12′（step4 真聊）→ 钩子 5′（"会聊天了，但创造呢？下一站工坊"）。

**急救表**

| 现象 | 原因 | 一句话修复 |
| --- | --- | --- |
| 说明书"不管用"，艾芯不理人设 | 写得太客气/太抽象 | 三要素逐条检查：角色具体到口头禅，边界用"不做什么"句式 |
| 艾芯越聊越跑偏 | 只 append 了 user，忘了 assistant | 你和它的话**都要**记进清单 |
| 失忆实验"没失忆" | fresh 清单里混进了旧消息 | 新清单里只放一条 user，从零开始 |
| 学生问出暴力/不当内容 | 测试边界 | 边界拒绝正是验收素材；同时提醒课纪：说明书也约束我们自己 |
| 聊天清单越来越长、越来越慢 | token 变多 | 正好讲计费原理；/reset 的价值（展示版有此命令） |

**话术**：说明书三要素 = **角色（你是谁）/口头禅（怎么说）/边界（不说什么）**；记忆清单 = **AI 的记忆是外挂的**，每次通话把整本聊天记录重新寄一遍（所以它"记得"，也所以它按字数收钱）；迭代 = **不是许愿，是调教**——测试、挑毛病、改一段、再测试。

## 4. 分层任务（全站）

- 基础：L1 step1–2（离线版 + 第一次真通话）、L2 step1–2（说明书 + 失忆实验）
- 进阶：L1 step3–4（接龙原理 + 换人设）、L2 step3（V1→V2 迭代）
- 挑战：双胞胎艾芯 / 混合芯 / 失忆全家桶
- 毕业验收：step4 和自己的艾芯真聊 ≥ 10 句，通过毕业检查单四项

## 5. 衔接钩子

- 承上：第二站通关画面"阳光重回地面" → 空荡的大地需要创造 → 卫星投下艾芯（第三幕的登场由第二幕的战果引出——叙事闭环要口头点一遍）
- 收口：码力学会说话 = 孩子学会"指挥 AI"
- 启下：会聊天 ≠ 会创造 → 下一站「码力创作工坊」写诗、画画、**给第二站游戏造新关卡**（体系闭环的最后一环）

## 6. 与试讲的接口

- 试讲切片建议（干中学机制指定本站为 AI 试讲课）：L1 step1→step2"从规则版笨艾芯到真艾芯秒答"（10–15 分钟，哇点 = 落差瞬间）；备选 L2 step2 失忆实验（哇点 = 删历史当场失忆）
- 磨法五维度照旧；AI 课专属加分动作：现场让 AI 当堂写诗（主文档面试叙事原话）、现场换人设展示"一句话改变 AI"
- 风险预案：现场断网 → 切离线版艾芯继续讲"对话=输入输出"主线，真 API 环节改为念报错讲排障（也能体现工程素养）

## 7. 教学设计决策（为什么这样切）

- **离线规则版起步（step1）**：零依赖保"能跑"底线（机构无网也能开课）；"查表 vs 接龙"对比是原理科普的最短路径
- **requests 裸调而非 SDK**：SDK 是黑盒（教学上每一行都要能解释）；requests 的"地址/门票/信件"比喻直白；且 Python 3.14 下 SDK 依赖链未验证（pygame 的教训）
- **先拆回信再封装 ask()**：step2 裸写看清结构，step3 因"连问 3 次"之痛自然引出 def——延续全体系"重复之痛 → 抽象"的能力主线（Scratch 重复执行 → for → def → API 封装）
- **失忆实验做成固定步骤**：这是本站认知价值最高的实验（AI 无脑内记忆、token 计费的根源），必须人人亲手做，不满足于教师演示
