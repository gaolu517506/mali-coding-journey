# 会聊天的码力（AI 对话 · 给艾芯写性格说明书）

> 第三幕 · 智慧站 ① ｜ 机制：LLM 人设对话 = 提示词设计 ｜ 2 课时 × 90 分钟
> 课纲关键词：**AI 对话 · LLM · 提示词工程 · 大模型 API · system 消息 · 多轮对话**

## 故事

轨道疏通了，码力回到空荡荡的大地。旧世界清空了，可只会干活的机器人想不出拿什么填满它。

这时，他在上一幕救回的卫星重新上线，向地面投下人类离开前封存的最后一件礼物——AI 大脑**艾芯**（谐音"爱心"）。装上艾芯的码力，学会了说话。

> 想直接体验成品？运行 [会聊天的码力-展示版.py](./会聊天的码力-展示版.py)：三套性格可切换、带记忆的终端聊天。

## 我会学到什么

| 课时 | 我做出什么 | 新超能力 |
| --- | --- | --- |
| 1 · 唤醒艾芯 | 从"只会查表的离线版"到调通真大模型，第一次和艾芯通话 | 大模型 API 调用、AI = 超级文字接龙的原理、system 设定消息、temperature |
| 2 · 性格说明书 | 一个按你的说明书说话、记得住聊天内容的艾芯 | 提示词三要素（角色/口头禅/边界）、messages 记忆清单、迭代式调教 |

核心理解一句话：**AI 没有"脑内记忆"，它每次都在重读你的聊天记录**——知道了这个，你就知道怎么用它、也更知道怎么防它。

## 准备环境（15 分钟，本站有网络要求）

1. 安装 [Thonny](https://thonny.org/)（前两站的老环境就行）
2. 安装 requests：Thonny 菜单 **工具 → 管理软件包**，搜索 `requests` → 安装
3. 申请一个大模型 API key（默认课程用[智谱开放平台](https://open.bigmodel.cn/)，`glm-4-flash` 模型免费）：
   - 注册后在本机配置环境变量 `ZHIPU_API_KEY`（macOS：终端执行 `echo 'export ZHIPU_API_KEY=你的key' >> ~/.zshrc` 后重开终端；Windows：系统设置 → 环境变量）
   - key 像门禁卡，**只放环境变量，绝不写进代码**（课程第 1 课会讲为什么）
4. 自检：新建文件运行 `import requests, os; print(bool(os.environ.get("ZHIPU_API_KEY")))`，打印 `True` 就绪

> 换别家大模型？课程代码是 OpenAI 兼容格式，改文件顶部配置区三行即可（DeepSeek / 通义对照注释已写好）。
> 没有网络或 key？第 1 课 step1 的离线版艾芯零依赖可跑，先玩它。

## 跟着做

> 每个步骤一个文件，卡住就对照文件里的注释。

### 第 1 课 · 唤醒艾芯（lesson1_唤醒艾芯/）

1. **step1 离线版艾芯**：if-else 规则库聊天机器人——60 年前的技术，也让你彻底搞懂"对话 = 输入 → 输出"
2. **step2 第一次通话**：requests 发出第一封"挂号信"，真大模型回话了（寄信地址、门票 key、信件三件套）
3. **step3 文字接龙**：同一个问题连问 3 遍——发现 AI 的秘密：它是超级接龙玩家；temperature 旋钮控制放飞程度
4. **step4 给艾芯下命令**：system 消息 = 设定说明书，一句话让艾芯变海盗/诗人
5. **challenge 猜猜它是谁**：5 发探测弹探 AI 的知识边界——它没有日历、没有眼睛，还会把不知道的编得像真的

### 第 2 课 · 性格说明书（lesson2_性格说明书/）

1. **step1 性格说明书**：人设三要素（角色/口头禅/边界）+ 四发验收弹
2. **step2 记忆的秘密**：messages 记忆清单——删掉历史，艾芯当场"失忆"（本站最大哇点）
3. **step3 调教艾芯**：V1 随手写 → 挑毛病 → V2 迭代——提示词工程是迭代，不是许愿
4. **step4 毕业作品**：说明书 + 记忆 + 聊天循环三件套总装，和自己的艾芯真实对话
5. **challenge 双胞胎艾芯**：同一颗大脑两份相反说明书——暖芯 vs 严芯同题对决

## 挑战任务

- ⭐ 给艾芯换一套你设计的口头禅和称呼
- ⭐⭐ 双胞胎艾芯 + 造出你的"混合芯"（先共情、再指问题、后给动作）
- ⭐⭐⭐ 失忆实验全家桶：assistant 消息也删掉会怎样？聊 20 句后它还记得第 1 句吗？
- 🏆 终极：给艾芯加一个"专属知识"（在 system 里写上你自己），让它变成"最懂你的艾芯"
