会聊天还不够——重建家园需要创造。码力在工坊里学会了请 AI 一起写诗、画画，甚至给清理飞船升级装备、生成全新的轨道关卡。

家园一点点建起来。码力向太空发出信号：**"回家吧。"**

## 跟着做

> 每个步骤一个文件，卡住就对照文件里的注释。

### 第 1 课 · 写诗工坊（lesson1_写诗工坊/）

1. **step1 第一首诗**：同一主题两份订单对比——"写首诗"（随口）vs 四要素订单（精确），差距一目了然
2. **step2 订单模板**：结构化提示词四件套（角色/任务/约束/示例），换货不换单
3. **step3 导演的三个回合**：初稿 → 提意见重拍 → 精修一处——人是导演，AI 是剧组
4. **step4 诗歌工坊**：一张订单要三首、程序自动拆货编号，你当主编选稿写推荐语
5. **challenge 主题诗集**：四个栏目供稿，排版成一本带目录的诗集文件

### 第 2 课 · 画画工坊（lesson2_画画工坊/）

1. **step1 画家的词汇表**：SVG 只认基础形状——超纲词（渐变/阴影/高光）一律禁止，订单体检员上岗
2. **step2 第一幅画**：AI 交回 SVG 代码画 → 存文件 → 浏览器打开——AI 的画也是代码
3. **step3 改画导演**：带着初稿提意见重画，两幅对比（导演不碰代码，只写意见）
4. **step4 家园画廊**：三联画（日出开工/种下树苗/星空下的家）+ 自动生成的画廊网页
5. **challenge 给码力画朋友**：闭集约束下的原创角色设计（三处特征 + 配色 + 名字）

### 第 3 课 · 关卡工厂（lesson3_关卡工厂/）

1. **step1 读懂图纸**：复习第二站字符地图（`.`/`G`/`H`/`J`），手工设计并程序预览体检
2. **step2 AI 画图纸**：给 AI 下硬约束订单，让它当关卡设计师（见识 AI 交稿的各种"包装"）
3. **step3 验证员上岗**：写程序给 AI 交稿做机器体检，不过就把报错发回让它重修——本课灵魂
4. **step4 毕业作品**：AI 设计的第 4 关通过体检后，按"三步上货指引"装进第二站游戏开打
5. **challenge 关卡策划师**：金字塔/笑脸/神秘图案三个主题批量下单、验收、评分、选优交货

## 挑战任务

- ⭐ 给订单模板换你自己的主题，出一首"你的诗"
- ⭐⭐ 诗集加"编者的话"；给三联画廊加第四幅画
- ⭐⭐⭐ 给验证员加第四条标准（如金垃圾 ≤ 4 个，防"金币雨"）
- 🏆 终极：设计你自己的关卡主题并让 AI 供货，真实打进第二站游戏，给 AI 的设计打分

## 体系大结局（三站闭环）

- 第一站：你在 Scratch 里指挥码力分拣垃圾，在星图上点亮五角星
- 第二站：你用 Python 造飞船，打通了全部三关
- 第三站：你指挥 AI 写诗、画画、**给第二站的游戏供货新关卡**——验证员程序替你把关
- 五个项目不是散装作业，是一个互相咬合的小世界。码力说：**"回家吧。"**
