> 面向授课教师。学生视角的玩法与跟做步骤见 [README.md](./README.md)。

## 1. 三维教学目标

| 维度 | 目标 |
| --- | --- |
| 知识 | Scratch：事件、循环、x 坐标、克隆、随机数、碰撞侦测、条件判断、变量、广播；通识：垃圾四分类 |
| 能力 | 把现实中的"分类"翻译成"如果…那么…"的条件判断（问题到程序的抽象迁移） |
| 情感 | 环保意识；"帮码力完成任务"的使命感与责任感 |

## 2. 课时分解与卡点急救表

单课时节奏（90 min）：故事一拍 3′ → 目标演示 5′ → 跟做 40′ → 自主改造 20′ → 展示互评 15′ → 钩子 5′。

### 课时 1 · 码力学会走路

产出：背景与码力角色就位，方向键控制左右移动且不出界。

| 现象 | 原因 | 一句话修复 |
| --- | --- | --- |
| 按一下键只动一步，按住不放不连续 | 按键判断没放进"重复执行" | 把判断包进重复执行 |
| 按右键往左走 | 负数方向搞反 | 记住"x 变小 = 向左"，左侧是负的 |
| 码力跑出屏幕消失 | 没做边界 | 加"如果 x > 220 就不再往右"（或"碰到边缘就反弹"） |

### 课时 2 · 垃圾从天而降

产出：垃圾随机位置生成、持续下落，被码力接到就消失并 +1 计分。

| 现象 | 原因 | 一句话修复 |
| --- | --- | --- |
| 垃圾本体一直停在舞台角落 | 本体没隐藏 | 本体"隐藏"，"当作为克隆体启动时"再"显示" |
| 落地后垃圾越堆越多、越来越卡 | 落地没删克隆体 | y 低于底线时"删除此克隆体" |
| 分数不动 | 变量没勾选显示 / 计分代码挂在错误角色上 | 变量勾选显示；计分放在能收到广播的角色或舞台 |

### 课时 3 · 分对才算数

产出：接到的垃圾顶在码力头上，按 1–4 投桶，对错反馈、污染条、结算画面。

本课最大教学难点：**克隆体的私有变量广播方读不到**——类别用私有变量（克隆时设置），投桶判定前先交接给全局变量"手上类别"。

## 3. 讲解话术库

- 克隆 = 影分身之术：本体藏在幕后，分身满天飞，干完活自己消失
- x 坐标 = 舞台的座位号：越往右号码越大，往左是负的
- 随机数 = 抽盲盒
- 如果…那么… = 分类员上岗：先看牌子，再决定扔哪个桶
- 广播 = 对讲机喊话，听到的人各自行动
- 舞台的代码 = 裁判席：计分、计时这些"全局的事"都归它管

## 4. 分层任务

- **基础**：跟做完成课堂版（单垃圾、无倒计时、8 种垃圾）
- **进阶**：连对奖励 ×3；加入陷阱垃圾（大棒骨属"其他"、湿纸巾不可回收）
- **挑战**：打地鼠变体——把下落逻辑反转为从地面冒出（y 方向逻辑反转），检验知识迁移

## 5. 衔接钩子

地面清完 → 抬头发现挡住阳光的轨道垃圾 → 可码力不会飞 → 第二幕（Python 海龟画图 = 飞行航线训练）。
