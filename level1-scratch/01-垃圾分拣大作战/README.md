## 故事

地球被垃圾淹没了，人类只好搬到太空去住。小机器人**码力**刚刚醒来，他的程序里写着最后一个任务：**把地球打扫干净，接人类回家。**

他学会的第一件事，就是分拣垃圾。嘀——码力启动！

## 怎么玩

- 垃圾会从天上掉下来，用 **← →** 键控制码力跑过去接住
- 接住后垃圾会顶在码力头上，按 **1 / 2 / 3 / 4** 把它丢进对的垃圾桶：
  - **1** 🔵 蓝 · 可回收物（矿泉水瓶、易拉罐、旧报纸、玻璃瓶、旧书本）
  - **2** 🟢 绿 · 厨余垃圾（香蕉皮、苹果核、菜叶、鱼骨头、西瓜皮）
  - **3** 🔴 红 · 有害垃圾（废电池、过期药、温度计、油漆桶、荧光灯管）
  - **4** 🟡 黄 · 其他垃圾（用过的纸巾、大棒骨、碎瓷碗、旧口罩、破旧球鞋）
- 分对 **+10 分**，投对还有清脆的"叮"；投错会有提示音，连对 ×3 还有额外奖励！
- 同时最多 4 件垃圾在场，60 秒倒计时结束，看看你帮码力拿到了几颗星！

## 跟着做

> 每节课做出一小块，三节课拼成完整游戏。卡住了就看"检查一下"，还卡就举手！

### 第 1 课 · 码力学会走路（40 分钟）

1. 把素材包里的**码力**角色导入舞台，摆到底部中间
2. 搭第一条脚本：
   ```scratch
   当 🟩 被点击
     移到 x:(0) y:(-35)
     重复执行
       如果 <<按下 [→] 键?> 且 <(x 坐标) < (200)>> 那么
         将 x 坐标增加 (8)
       如果 <<按下 [←] 键?> 且 <(x 坐标) > (-200)>> 那么
         将 x 坐标增加 (-8)
   ```
3. 点绿旗试玩：按住方向键，码力应该顺滑地跑起来，两边不会冲出屏幕

**检查一下**：按一下键只动一小步？——把"如果"包进"重复执行"里。左右反了？——记住往左是负数。

### 第 2 课 · 垃圾从天而降（40 分钟）

1. 导入**垃圾**角色（一共有 20 个造型），加两个"仅适用于当前角色"的变量：`类别`、`携带中`，再建列表 `类别表`（按造型顺序填 20 个颜色）
2. 垃圾本体：绿旗 → **隐藏** → 重复执行 ｛随机等待 0.6~1.4 秒 → 如果 <(在场垃圾数)<(4)> 那么 克隆 [自己]｝
3. 克隆体的脚本（"当作为克隆体启动时"）：
   ```scratch
   当作为克隆体启动时
     将 [在场垃圾数] 增加 (1)
     显示
     换成 (在 1 和 20 之间取随机数) 号造型
     将 [类别] 设为 (第 (造型编号) 项，项目 [类别表])
     移到 x:(在 -200 和 200 之间取随机数) y:(180)
     重复执行
       将 y 坐标增加 (0 - (速度))
       ……（第 3 课在这里接"接住"和"落地"）
   ```
4. 先加落地：`如果 <(y 坐标) < (-160)> 那么 将 [连对] 设为 0 → 在场垃圾数 -1 → 删除此克隆体`

**检查一下**：垃圾堆在角落不掉？——本体要"隐藏"，克隆体启动时要"显示"。越玩越卡？——落地记得"删除此克隆体"。

### 第 3 课 · 分对才算数（40 分钟）

1. 摆好四只垃圾桶（蓝绿红黄各就各位），每只桶两条脚本：`当按下 [1] 键 → 广播 [投入-蓝]`、`当角色被点击 → 广播 [投入-蓝]`
2. 接住垃圾：在克隆体的下落循环里加
   ```scratch
   如果 <碰到 [码力]?> 那么
     如果 <(手里的垃圾) = (空)> 那么
       将 [手里的垃圾] 设为 (类别)      ← 把类别抄给全场看
       将 [携带中] 设为 (1)
       广播 [接住]
       重复执行直到 <不 <(手里的垃圾) = (类别)>>
         移到 x:([x 位置] 关联 [码力]) y:(([y 位置] 关联 [码力]) + 110)
   ```
3. 投桶判定（垃圾角色里 ×4 条，每条对应一种颜色）：
   ```scratch
   当接收到 [投入-蓝]
     如果 <(携带中) = (1)> 那么
       如果 <(类别) = (蓝)> 那么
         播放声音 [叮] → 分数 +10 → 连对 +1 →（连对>2 再 +10）→ 滑行进桶
       否则
         播放声音 [错] → 连对 设为 0
       手里的垃圾 设为 空 → 在场垃圾数 -1 → 删除此克隆体
   ```
4. 舞台加"裁判"脚本：倒计时 60 秒、每秒 `时间 -1`、速度 = 4 + (60-时间)/8、时间=0 广播 [结算]
5. 码力加结算：按分数给 ★→★★★，说"时间到！得分……"，停止全部
6. 背景音乐（舞台）：`绿旗 → 重复执行 ｛播放声音 [Video Game 1] 等待完毕｝`

**检查一下**：分对也不加分？——"类别"是克隆体的私有变量，广播方读不到，要先交接给全局"手里的垃圾"。音乐只播一遍？——"播放直到结束"要包在"重复执行"里，而且音乐要独立成一条脚本。
