## 故事

地球被垃圾淹没了，人类只好搬到太空去住。小机器人**码力**刚刚醒来，他的程序里写着最后一个任务：**把地球打扫干净，接人类回家。**

他学会的第一件事，就是分拣垃圾。嘀——码力启动！

## 怎么玩

- 垃圾会从天上掉下来，用 **← →** 键控制码力跑过去接住
- 接住后垃圾会顶在码力头上，按 **1 / 2 / 3 / 4** 把它丢进对的垃圾桶：
  - **1** 🔵 蓝 · 可回收物（矿泉水瓶、易拉罐、旧报纸、玻璃瓶、旧书本）
  - **2** 🟢 绿 · 厨余垃圾（香蕉皮、苹果核、菜叶、鱼骨头、西瓜皮）
  - **3** 🔴 红 · 有害垃圾（废电池、过期药、温度计、油漆桶、荧光灯管）
  - **4** 🟡 黄 · 其他垃圾（用过的纸巾、大棒骨、碎瓷碗、旧口罩、破旧球鞋）
- 分对 **+10 分**，投对还有清脆的"叮"；投错会有提示音，连对 ×3 还有额外奖励！
- 同时最多 4 件垃圾在场，60 秒倒计时结束，看看你帮码力拿到了几颗星！
