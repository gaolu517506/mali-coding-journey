# 积木总览 · 垃圾分拣大作战

> 本文件是游戏的完整积木清单，按角色分组，用伪 Scratch 代码写成。用途：① 教师逐块复讲（"能讲"自测）；② 课堂版/展示版参数调整；③ 想在 Scratch 里手动重建时的对照蓝图。

## 全局设定

**变量（7 个，全部在舞台上）**：`分数`、`时间`（60 秒倒计时）、`手里的垃圾`（空/蓝/绿/红/黄）、`连对`、`速度`（下落速度，随时间加快）、`在场垃圾数`（同屏并发计数，上限 4）、`星级`

**私有变量（2 个，只在"垃圾"角色）**：`类别`（每个克隆体各自的垃圾类别）、`携带中`（标记是否是被接住的那个克隆体）

**列表（垃圾角色）**：`类别表` = [蓝×5, 绿×5, 红×5, 黄×5]，与 20 个造型一一对应

**广播（6 条）**：`接住` / `投入-蓝` / `投入-绿` / `投入-红` / `投入-黄` / `结算`

**音效（4 个）**：`Video Game 1`（官方素材 7.8s，舞台背景音乐循环）· `pop`（官方素材，接住）· `叮`（合成：E6→G6 上行两音，投对）· `错`（合成：A4→F4 下行两音，投错）

## 舞台

```scratch
当 🟩 被点击
  将 [分数] 设为 0
  将 [污染] 设为 0
  将 [时间] 设为 60
  将 [手上类别] 设为 (空)
  将 [连对] 设为 0
  将 [清理数] 设为 0
  将 [速度] 设为 4

当 🟩 被点击                              ← 计时与提速（第二条脚本）
  重复执行
    等待 1 秒
    将 [时间] 增加 (-1)
    将 [速度] 设为 (4 + ((60 - 时间) / 8))   ← 4 → 11.5，越到后面越快
    如果 <(时间) = 0> 那么
      广播 [结算]

当 🟩 被点击                              ← 背景音乐（第三条脚本，独立成条）
  重复执行
    播放声音 [Video Game 1] 等待完毕         ← 播完一遍自动重播；结算"停止全部"时随脚本一起停
```

## 码力

```scratch
当 🟩 被点击
  说 "← → 移动！接住垃圾，按 1蓝 2绿 3红 4黄 投桶！" (2) 秒
  移到 x:0 y:-35
  换成 [码力-常规] 造型
  显示
  重复执行
    如果 <<按下 → 键?> 且 <(x 坐标) < (200)>> 那么
      将 x 坐标增加 8
    如果 <<按下 ← 键?> 且 <(x 坐标) > (-200)>> 那么
      将 x 坐标增加 (-8)

当接收到 [接住]                            ← 接住的表情反馈
  播放声音 [pop]
  换成 [码力-开心] 造型
  等待 0.3 秒
  换成 [码力-常规] 造型

当接收到 [结算]                            ← 星级结算
  如果 <(分数) > (299)> 那么
    将 [星级] 设为 ★★★
  否则
    如果 <(分数) > (199)> 那么
      将 [星级] 设为 ★★
    否则
      如果 <(分数) > (99)> 那么
        将 [星级] 设为 ★
      否则
        将 [星级] 设为 (码力还在练习！)
  说 (连接 "时间到！得分 " (连接 (分数) (连接 " " (星级))))   ← 说（不等待）：气泡保留，随后立即停止
  停止 [全部]
```

## 垃圾（1 个角色，20 个造型：蓝5/绿5/红5/黄5 各 5 种）

```scratch
当 🟩 被点击                                ← 生成本体（本体隐藏，只派克隆体）
  隐藏
  重复执行
    等待 (在 0.6 和 1.4 之间取随机数) 秒
    如果 <(在场垃圾数) < (4)> 那么          ← 同屏上限 4
      克隆 [自己]

当作为克隆体启动时                          ← 一条垃圾的完整一生
  将 [在场垃圾数] 增加 1
  移到最前面
  显示
  换成 (在 1 和 20 之间取随机数) 号造型
  将 [类别] 设为 (第 (造型编号) 项，项目 [类别表])
  将 [携带中] 设为 0
  移到 x: (在 -200 和 200 之间取随机数) y: 180
  重复执行
    将 y 坐标增加 (0 - (速度))              ← 下落
    如果 <碰到 [码力]?> 那么
      如果 <(手里的垃圾) = (空)> 那么          ← 码力手里没拿东西才接
        将 [手里的垃圾] 设为 (类别)
        将 [携带中] 设为 1
        广播 [接住]
        重复执行直到 <不 <(手里的垃圾) = (类别)>>   ← 跟随头顶，直到被投出去
          移到 x: ([x位置] 关联 [码力]) y: (([y位置] 关联 [码力]) + 110)
    如果 <(y 坐标) < (-160)> 那么           ← 落地没接住
      将 [连对] 设为 0                      ← 漏接只断连对，无污染机制
      将 [在场垃圾数] 增加 -1
      删除此克隆体

当接收到 [投入-蓝]                          ← ×4，蓝/绿/红/黄各一条，仅"携带中"的克隆体响应
  如果 <(携带中) = (1)> 那么
    如果 <(类别) = (蓝)> 那么               ← 分对
      播放声音 [叮]                         ← 清脆正确音
      将 [分数] 增加 10
      将 [连对] 增加 1
      如果 <(连对) > (2)> 那么              ← 连对 ×3 奖励
        将 [分数] 增加 10
        将 [连对] 设为 0
      在 0.2 秒内滑行到 x:(-180) y:(-136)
    否则                                    ← 分错
      播放声音 [错]                         ← 低沉提示音
      将 [连对] 设为 0
    将 [手里的垃圾] 设为 (空)                  ← 交还"手"，允许接下一件
    将 [在场垃圾数] 增加 -1
    删除此克隆体
```

> 造型为带文字标签的位图（PNG @2x）：蓝「可回收物」/ 绿「厨余垃圾」/ 红「有害垃圾」/ 黄「其他垃圾」

```scratch

当按下 [1] 键                                ← 各桶绑定 1/2/3/4
  广播 [投入-蓝]

  广播 [投入-蓝]
```

## 课堂版 ↔ 展示版（同一套代码，只调数值）

| 参数 | 课堂版 | 展示版 |
|---|---|---|
| `速度` 基数 | 固定 2（把舞台第二脚本里的提速行删掉） | 4 + (60-时间)/8 |
| `时间` 初值 | 不要（把倒计时脚本停用） | 60 |
| 生成间隔 | 1.5 ~ 3 秒 | 0.6 ~ 1.4 秒 |
| 同屏上限 | 1（生成器里 < 4 改 < 1） | 4 |
| 垃圾种类 | 20 种 | 20 种（含陷阱题大棒骨） |

## 已知简化与扩展点（留给课堂 / 学生改造）

1. **没有结算画面背景**——结算靠码力说话 + 监视器。扩展：加"结算画面"背景，在码力脚本里"换成背景"。
2. **接住时手里已拿垃圾会忽略新垃圾**——垃圾会穿过码力落地。这是有意设计（逼玩家先投桶）。
3. **漏接无惩罚**（除断连对）——孩子压力更小；想要挑战可加回"污染"变量。
4. **打地鼠变体**：把"重复执行 {将 y 坐标增加 -速度}"的反向改成从地面 y=-160 冒出到 y=60 再落下，即"垃圾冒出来"模式（教师笔记分层挑战）。
