# 码力的星空（Python 海龟画图 turtle）

> 第二幕 · 造物站 ① ｜ 机制：海龟画图 turtle = 飞行航线模拟 ｜ 3 课时 × 90 分钟（规划）
> 课纲关键词：**Python · 海龟画图 turtle · for 循环 · 坐标 goto · 函数 def**

## 故事

想上天，先学会"算"。上飞船之前，码力要在一台星图终端上练习飞行：让海龟画笔替它在星图上画出航线，把散落的星星连成星座、点亮航标——航线解锁的那天，就是飞船升空的日子。

## 我会学到什么

| 课时 | 我做出什么 | 新超能力 |
| --- | --- | --- |
| 1 · 航线训练 | 从手动飞行到 for 循环，画正方形和**五角星** | import、turtle 前进/转弯、for 循环、角度的数学 |
| 2 · 星图坐标 | 精确飞到坐标，连出**北斗七星**，撒一片星野 | goto 坐标、penup/pendown（起飞/降落）、random 随机 |
| 3 · 函数工厂 | 把画星星打包成 `draw_star()`，铺满整片星空 | def 函数、参数、调用——毕业作品《码力的星空》 |

## 准备环境（5 分钟）

- 安装 [Thonny](https://thonny.org/)（推荐，自带 Python，解压即用），或者用带 Tk 的 Python + IDLE
- 打开 Thonny，新建文件，第一行输入 `import turtle`，运行——弹出一个星空窗口就说明环境 OK

## 跟着做

> 每个步骤一个文件，在 `lesson1_航线训练/` 文件夹里，卡住就对照文件里的注释。

1. **step1 手动飞行**：让海龟飞出一个 L 形。你会写到手酸——这就是 for 循环要解决的问题
2. **step2 正方形循环**：`for i in range(4)` 四行变两行；试试改成 3 和 6，发现外角 = 360 ÷ 边数
3. **step3 五角星**：5 条边 + 每次右转 144°——海龟转了整整两圈，星星就是这么来的
4. **step4 彩虹五角星**：列表装颜色，循环里挨个换色
5. **challenge 任意 n 角星**：你问几角它画几角。试试 6——咦，怎么变成两个三角形了？

## 挑战任务

- ⭐ 给五角星换颜色、换大小、换粗细
- ⭐⭐ 用 `begin_fill()` / `end_fill()` 把五角星变成实心的
- ⭐⭐⭐ n 角星生成器 + 解释"为什么 6 角星会变成两个三角形"
- 🚀 预习挑战：不查资料，猜猜怎么让海龟"瞬移"到指定位置（下一课揭晓）
