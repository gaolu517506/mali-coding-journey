# 教师笔记 · 码力的星空（3 课时全集）

> 面向授课教师。学生视角见 [README.md](./README.md)；每课代码见 `lessonN_*/` 各 step 文件注释。

## 1. 三维教学目标（分课）

| 课时 | 知识 | 能力 | 情感 |
| --- | --- | --- | --- |
| 1 · 航线训练 | import、对象与方法、for 与 range、外角 = 360°÷n、缩进；彩蛋：五角星转 720° | 把重复抽象成循环；Scratch→Python 迁移（重复执行 → for） | "航线解锁"目标感；发现数学规律的惊喜 |
| 2 · 星图坐标 | goto(x, y) 坐标系、penup/pendown、random.randint、列表存坐标、for 解包、嵌套循环 | 用坐标表组织空间数据；从"连线思维"到"点位思维" | 北斗成形的成就感；随机星野的审美惊喜 |
| 3 · 函数工厂 | def 定义与调用、参数、封装与复用；通识：函数 = Scratch 自制积木 | 把一段动作打包成可复用积木；主程序"只剩指挥"的工程感 | 毕业作品的仪式感；"我也能造积木"的创作者身份 |

**课纲关键词**：Python · 海龟画图 turtle · for 循环 · 坐标 goto · 函数 def —— 学生版 README 首行可见。

## 2. 环境准备（三课通用）

- **推荐 Thonny**（thonny.org，自带 Python 与 Tk，解压即用）；机构若统一 IDLE 亦可（python.org 版 Python 自带 Tk）
- ⚠️ Homebrew 安装的 Python 默认**不带 Tk**，`import turtle` 会报 `No module named '_tkinter'`——课前务必逐一检查：新建文件输入 `import turtle` 运行，能弹出窗口才算过
- 窗口"一闪而过"的解法：脚本末尾加 `turtle.done()`
- 第 3 课结束建议现场让学生截屏毕业作品（家长群展示素材）

## 第 1 课 · 航线训练（lesson1_航线训练/）

**节奏（90 分钟）**：故事一拍 3′ → 目标演示 5′ → 跟做 40′（step1→step2→step3）→ 自主改造 20′（step4 / challenge）→ 展示互评 15′ → 钩子 5′。

**跟做要点**：step1 故意让学生写到手酸（只给 L 形），"写到手酸"就是引入 for 的最佳时机——不要提前剧透循环。

**卡点急救表**

| 现象 | 原因 | 一句话修复 |
| --- | --- | --- |
| `No module named '_tkinter'` | Python 编译时没带 Tk | 换 Thonny 或 python.org 版 Python |
| `NameError: name 't' is not defined` | 漏 `t = turtle.Turtle()` | 先造训练舱，再下指令 |
| `IndentationError` | 循环体没缩进 | 循环体内的行，开头敲 4 个空格 |
| 窗口一闪而过 | 少了 `turtle.done()` | 末尾加 `turtle.done()` |
| 画出来的不是星形 | 角度写错（90 ≠ 144） | 五角星转角是 144，不是 72 |
| 海龟走得慢 | 默认速度 | `t.speed(0)` 极速模式 |

**讲解话术**

- import = **借工具箱**；`t = turtle.Turtle()` = **造训练舱**；`t.forward(100)` 和 Scratch"移动 100 步"是同一块积木，只是从拖变成了打字
- for 循环 = **复读机**：`range(4)` 就是"复读 4 遍"；缩进 = 循环体的"房间"
- 360°÷n = **转一圈的数学**；720 = **星星的秘密**（比正方形多绕一圈）

**分层任务**：基础 step1–3 → 进阶 step4 彩虹星 + begin_fill 实心星 → 挑战 challenge n 角星生成器（720÷n，六角星拆成两个三角形的彩蛋）。

**收课钩子**："真正的星图上星星是散落的点——怎么让海龟瞬移到指定位置？下一课揭晓。"（step3/README 预习挑战埋点）

## 第 2 课 · 星图坐标（lesson2_星图坐标/）

**节奏（90 分钟）**：钩子回收 5′（揭晓瞬移）→ 演示北斗成品 3′ → 跟做 45′（step1→step2 → step3）→ 自主改造 20′（step4）→ 展示互评 12′ → 钩子 5′。

**跟做要点**：step2 的坐标表是本课认知高点——"每颗星是一个装着 [x, y] 两个数的小口袋"。先让学生手改 1~2 个数字看勺子变形，再进入循环连线，坐标感就立住了。step4 的嵌套循环只讲"大圈套小圈"，不引入"嵌套"术语本身。

**卡点急救表**

| 现象 | 原因 | 一句话修复 |
| --- | --- | --- |
| `NameError: name 'random' is not defined` | 忘了 `import random` | 骰子大师要先请进门 |
| 星星跑到窗口外看不见 | 坐标太大（超出 ±350/±250 附近） | x 控制 -350~350，y 控制 -250~250 |
| 后面的画全都消失了 | penup 之后忘了 pendown | 起飞后记得降落 |
| 勺子形状不对、绕来绕去 | 坐标表顺序打乱 | 连线按表内顺序飞，天枢→…→摇光 |
| `ValueError: too many values to unpack` | for x, y 的表里塞了 3 个数 | 每颗星只装 x、y 两个数 |
| 嵌套循环里星都画在同一点 | goto 写到了内层循环里 | 先 goto 到位（外层），再画星（内层） |

**讲解话术**

- penup/pendown = **起飞/降落**：起落架收起来飞过不留痕，放下来又开始画
- goto = **空间传送**：Scratch 的"移到 x y"就是它；坐标 = 星图的**门牌号**（从中心往右数是 x、往上数是 y）
- random.randint = **掷骰子**：括号里是骰子的最小最大点数
- 嵌套循环 = **大圈套小圈**：外面一圈数星星（飞到位），里面一圈画星星（五步曲）
- 坐标表 = **每颗星一个小口袋**，`for x, y in stars` 一次掏出两个数

**分层任务**：基础 step1–2（起飞降落 + 北斗连线）→ 进阶 step3–4（星野 + 七星变亮）→ 挑战 challenge 我的星座（自造坐标 + 命名 + write 签名）。

**收课钩子**："画一颗星 5 行代码，想在别的地方再画就得整段抄——有没有办法把'画一颗星'打包成一块积木？下一课：函数工厂。"（step4 观察注释埋点）

## 第 3 课 · 函数工厂（lesson3_函数工厂/）

**节奏（90 分钟）**：钩子回收 + Scratch 自制积木对照 5′ → 演示毕业作品 3′ → 跟做 40′（step1→step2→step3）→ 毕业作品 25′（step4）→ 作品展示互评 15′（拍照/截屏）→ 下站钩子 2′。

**跟做要点**：本课的锚是 **Scratch 自制积木 → def** 的迁移（面试讲体系的核心证据之一）。step1 务必让学生做"数行数"对比（不用 def 三颗星要 15 行画星代码，用了只要 3 行调用）；step4 毕业作品控制在跟做内完成，主程序"指挥"的干净感要现场指给学生看。

**卡点急救表**

| 现象 | 原因 | 一句话修复 |
| --- | --- | --- |
| `SyntaxError`，光标停在 def 行 | def 行末忘了冒号 | def draw_star(size, color):  冒号收尾 |
| 函数体报 IndentationError | def 里面的代码没缩进 | def 里的行整体再缩 4 格 |
| 屏幕上什么都没有 | 只定义了没调用 | 定义积木 ≠ 使用积木，画星要喊 draw_star() |
| `TypeError: draw_star() missing ...` | 调用时少给了参数 | 两个旋钮都要拧：draw_star(50, "gold") |
| 星星颜色是变量名色/报错 | 参数顺序传反 | size 在前 color 在后；颜色要带引号 |
| def 里用到 t 却报 NameError | def 写在了造 t 之前 | 先 import + 造 t，再打包积木 |

**讲解话术**

- def = **自制积木**：Scratch 里"制作新的积木块"，Python 里就是 def——进阶不是换工具，是同一件事的进化
- 定义 ≠ 使用 = **造积木 ≠ 按积木**：def 只是把它装进盒子，喊名字（调用）才开始工作
- 参数 = **积木上的旋钮**：Scratch 自制积木加"输入数字"，Python 在括号里写 size、color
- 改一处处处生效 = **说明书只有一份**：改 def 里的 50→90，所有星星一起变大
- step4 的结构 = **工厂区和指挥区**：工厂造积木（两个 def），主程序只剩指挥——"这就是程序员的日常"

**分层任务**：基础 step1–2（打包 + 旋钮）→ 进阶 step3 流水线（函数+循环+随机合体）→ 挑战 challenge 造月亮（两圆相减 + circle）+ 流星；毕业 = step4《码力的星空》运行 + 截屏。

**收课钩子**："航线解锁，星图点亮。但星图上的清理目标是**会动的**——下一站，造飞船打垃圾。"（衔接第二站② pygame）
