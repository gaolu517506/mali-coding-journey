## 3. 环境准备

- **推荐 Thonny**（thonny.org，自带 Python 与 Tk，解压即用）；机构若统一 IDLE 亦可（python.org 版 Python 自带 Tk）
- ⚠️ Homebrew 安装的 Python 默认**不带 Tk**，`import turtle` 会报 `No module named '_tkinter'`——课前务必逐一检查：新建文件输入 `import turtle` 运行，能弹出星空窗口才算过
- 窗口"一闪而过"的解法：脚本末尾加 `turtle.done()`

## 4. 卡点急救表

| 现象 | 原因 | 一句话修复 |
| --- | --- | --- |
| `No module named '_tkinter'` | Python 编译时没带 Tk | 换 Thonny 或 python.org 版 Python |
| `NameError: name 't' is not defined` | 用了 t 但没造 t（漏 `t = turtle.Turtle()`） | 先造训练舱，再下指令 |
| `IndentationError` | 循环体没缩进 | 循环体内的行，开头敲 4 个空格 |
| 窗口一闪而过 | 少了 `turtle.done()` | 末尾加 `turtle.done()` |
| 画出来的不是星形 | 角度写错（90 ≠ 144） | 五角星转角是 144，不是 72 |
| 海龟走得慢 | 默认速度 | `t.speed(0)` 极速模式 |

## 5. 讲解话术库

- import = **借工具箱**：turtle 模块是 Python 自带的飞控系统，说一声 import 就借来了
- `t = turtle.Turtle()` = **造训练舱**：造出一架训练舱给它起名叫 t；`t.forward(100)` 就是下指令"前进 100"——和 Scratch 的"移动 100 步"是同一块积木，只是从拖变成了打字
- for 循环 = **复读机**：`range(4)` 就是"复读 4 遍"；缩进 = 循环体内的"房间"，在房间里的话才被复读
- 360°÷n = **转一圈的数学**：不管几边形，转完一圈总是 360 度
- 720 = **星星的秘密**：五角星每个尖角 36°，海龟每次转的是外面的 144°，五次转了 720°——星星比正方形多绕一圈
