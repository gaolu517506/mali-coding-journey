# 教师笔记 · 太空垃圾清理战（5 课时全集）

> 面向授课教师。学生视角见 [README.md](./README.md)；每课代码见 `lessonN_*/` 各 step 文件注释；完整成品见 `太空垃圾清理战-展示版.py`。

## 1. 三维教学目标（分课）

| 课时 | 知识 | 能力 | 情感 |
| --- | --- | --- | --- |
| 1 · 造一扇舷窗 | init/set_mode、事件与 QUIT、主循环、fill+flip、clock.tick、帧动画、列表管角色 | 建立"每帧重画"的心智模型 | 第一次点亮自己游戏窗口的仪式感 |
| 2 · 驾驶飞船 | get_pressed 持续输入、KEYDOWN 单次事件、Rect 对象、边界判断 | 区分"持续动作"与"一次性动作"两种交互 | "飞船听我指挥"的掌控感 |
| 3 · 发射能量球 | 速度向量、y 轴方向、反弹=速度取反、colliderect、命中角度 | 把物理直觉翻译成 if 条件 | 控球成功的操作快感 |
| 4 · 垃圾矩阵 | 嵌套循环、[Rect, 颜色] 列表结构、遍历中删除（[:] 复印件）、font 渲染、f-string | 数据组织：一类角色一份名单 | 击碎垃圾的爽感 + 分数上涨的即时反馈 |
| 5 · 轨道疏通 | 游戏状态（字符串状态机）、生命系统、胜负判定、关卡数据驱动 | "改数据不改逻辑"的工程思维 | 通关"阳光重回地面"的叙事高潮 |

**课纲关键词**：Python · pygame · 游戏开发 · 打砖块 · 碰撞检测 · 事件驱动 —— 学生版 README 首行可见。

**贯穿口诀**：主循环 = **听 → 算 → 画 → 等**。第 1 课建立，之后每课代码的注释都按这四步分节——学生迷路时问一句"你现在在哪一步？"

## 2. 环境准备（⚠️ 本站与星空站不同，有安装步骤）

1. Thonny（thonny.org）+ **pygame-ce**：Thonny 菜单「工具 → 管理软件包」搜 `pygame-ce` 安装；命令行 `pip install pygame-ce`
2. 为什么是 pygame-ce 而不是 pygame：官方 pygame 对新版本 Python（3.13+）没有预编译包、安装会编译失败；pygame-ce 是社区延续版，Windows/macOS 都有现成包，代码里仍是 `import pygame`，完全兼容
3. 课前逐一检查：新建文件运行 `import pygame` + `pygame.init()`，无报错才算过
4. **中文字体坑（重要）**：`SysFont(None, ...)` 默认字体不含中文，所有中文渲染成豆腐块 □。全部课程代码统一使用：
   `pygame.font.SysFont("microsoftyahei,hiraginosansgb,arialunicode", 32)`
   （名单里谁在用谁：Windows 找微软雅黑，Mac 找冬青黑体 / Arial Unicode）
5. pygame 不依赖 Tk（与 turtle 不同），任何正常 Python 均可运行；但教学环境仍统一 Thonny，减少变量

## 3. 每课结构与卡点急救

### 第 1 课 · 造一扇舷窗（lesson1_造一扇舷窗/）

**节奏（90 分钟）**：故事一拍 3′（航线练成 → 造飞船先造舷窗）→ 演示展示版 5′（"五节课后你做出这个"）→ 跟做 40′（step1→step2→step3）→ 自主改造 20′（step4）→ 展示 15′ → 钩子 5′（"飞船还不会动——下一课驾驶舱"）。

**急救表**

| 现象 | 原因 | 一句话修复 |
| --- | --- | --- |
| `ModuleNotFoundError: No module named 'pygame'` | pygame-ce 没装 / 装到了别的 Python | Thonny 里装；确认用的解释器是 Thonny 自带 |
| 窗口弹出后"未响应" | 忘了处理事件或死循环里没有 event.get() | 主循环第一件事：for event in pygame.event.get() |
| 画面全黑/全白不更新 | 忘了 pygame.display.flip() | 每帧末尾翻页 |
| 动画卡成幻灯片 | 忘了 clock.tick(60) 或帧率写太低 | 主循环末尾 clock.tick(60) |
| 星星拖出长尾巴 | 注释掉了 fill（这既是坑也是教学点） | 每帧先 fill 再画 |

**话术**：init = **点火**；主循环 = **心脏**（每秒跳 60 下，停了游戏就死）；fill+flip = **先擦黑板再写字、写完亮出来**；tick = **心跳节拍器**；列表 = **角色大名单**。

### 第 2 课 · 驾驶飞船（lesson2_驾驶飞船/）

**节奏**：钩子回收 3′ → 跟做 45′（step1→step2→step3→step4）→ 自主改造 20′（challenge）→ 展示 15′ → 钩子 5′（"飞船只会躲——武器呢？"）。

**急救表**

| 现象 | 原因 | 一句话修复 |
| --- | --- | --- |
| 飞船不动 | keys 判断写在主循环外 / 键名拼错 | get_pressed 每帧都要问；是 K_LEFT 不是 LEFT |
| 飞船一闪一闪乱飞 | 把移动写进 KEYDOWN（每按一下只动一帧） | 持续移动放 get_pressed，别放事件里 |
| 飞船穿出右边界消失 | 右护栏没减船宽 | 护栏 = W - ship.width |
| 走一格停一下像卡顿 | 速度太小（如 1） | 6 是顺手的巡航速度 |

**话术**：Rect = **身份证**（记位置和大小，centerx/bottom 等信息随取随用）；get_pressed = **每帧点名**（现在谁被按着？）；KEYDOWN = **门铃**（只在按下一瞬响）；"走马灯实验"（把换涂装放进 get_pressed）是本课最有说服力的对比演示，务必现场做。

### 第 3 课 · 发射能量球（lesson3_发射能量球/）

**节奏**：钩子回收 2′ → 跟做 50′（step1→step2→step3 是重点，step4 视班情选做）→ 自主改造 20′ → 展示 13′ → 钩子 5′（"球有了，垃圾呢？"）。

**急救表**

| 现象 | 原因 | 一句话修复 |
| --- | --- | --- |
| 球往上飞却"消失"了 | y 轴向下为正没理解透 | 向上 = y 变小 = 竖速为负 |
| 球粘在飞船上抖 | 反弹后没把球顶出飞船 | 反弹后加 ball.bottom = ship.top |
| 球穿墙而过 | 只判断了一面墙 / 速度太快 | 左右墙都要判；穿隧现象点到为止 |
| 球贴着天花板横飞 | 角度反弹把竖速算成 0 | 竖速保底：-max(3, ...) |

**话术**：速度 = **每帧挪几步**（两个数：横一步竖一步）；反弹 = **把那个方向的速度反过来**（位置回去没用，速度掉头才出得去）；colliderect = **两张身份证碰一碰**；控球 = **打在哪、飞向哪**（用船边缘接球试试）。

### 第 4 课 · 垃圾矩阵（lesson4_垃圾矩阵/）

**节奏**：跟做 45′（step1→step2→step3）→ 自主改造 25′（step4 计分 + challenge 特殊垃圾）→ 展示 15′ → 钩子 5′（"打光所有垃圾算赢吗？游戏还没有'赢'——下一课"）。

**急救表**

| 现象 | 原因 | 一句话修复 |
| --- | --- | --- |
| 遍历删除时报错/漏删 | 边遍历边删原件 | 用 trashes[:] 复印件遍历（口诀：先复印名单再划名字） |
| 中文显示成 □□□ | SysFont(None) 默认字体无中文 | 用课程代码里的中文字体名单（见环境准备） |
| f-string 少了 f 前缀 | 写成 "分数: {score}" | f"..." 才会把大括号换成真值 |
| 砖块最后一列溢出屏幕 | 列数改了间距没变 | 用 gap = (W - 40) / cols 自动算（第 5 课 build_trashes 示范） |

**话术**：嵌套循环 = **大圈套小圈**（外圈数行、内圈数列，和星空站画北斗是同一招）；[:] = **先复印名单**；font = **水笔**，render = **写出字片**，blit = **把字片贴上去**；f-string = **会说话的字符串**。

### 第 5 课 · 轨道疏通（lesson5_轨道疏通/）

**节奏**：跟做 40′（step1→step2→step3）→ **毕业作品总装 30′**（step4）→ 通关互拍 15′（截屏/录屏，家长群素材）→ 下站钩子 5′（叙事收口：阳光重回地面 → 地面重建 → AI 登场）。

**急救表**

| 现象 | 原因 | 一句话修复 |
| --- | --- | --- |
| Game Over 后球还在飞 | 运动结算没包进状态判断 | 只在 state == "playing" 时结算 |
| 过关后进下一关没垃圾 | 忘了重新 build_trashes | 每次进关都要按 LEVELS 重建 |
| 按空格没反应 | 状态判断条件没覆盖当前状态 | 检查 KEYDOWN 分支的 state 集合 |
| 三关全通后黑屏 | 漏了 final 状态的画面分支 | 画的部分 if/elif 要覆盖所有状态 |

**话术**：游戏状态 = **红绿灯**（playing 绿灯通行 / win、over 红灯停下看结果）；关卡表 = **设计图纸**（改图纸不用改机器）；字符地图 = **一格一字母，你画的就是轨道上的阵型**；通关画面 = 叙事回收（"轨道疏通，阳光重回地面"——第二幕在这一刻闭环）。

## 7. 教学设计决策（为什么这样切）

- **过程式主线 + 对象雏形**：全程用变量 + Rect + 列表，不引入 class——11–14 岁第一门 pygame 课先保"每行都能解释"；Rect 对象 + 列表管理同类角色即"面向对象雏形"，完整 sprite 类留作进阶扩展点（教师笔记记录，学生版不展开）
- **纯代码绘制、零图片素材**：与星空站"作品即代码"一致；打砖块天然是矩形；也规避了素材版权与加载失败两类课堂风险。音效按熔断预案先砍，列为扩展点（pygame.mixer 六行即可加）
- **碰撞简化**：球-砖碰撞统一按"竖速取反"处理（不做碰撞面判定），教学负荷最小；穿隧现象在小实验中点到，留给课后探索
- **中文字体名单**：见环境准备第 4 条——这是 pygame 中文教学的真坑，本课程所有代码已内置修复
