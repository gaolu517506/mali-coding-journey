# 码力回家 · mali-coding-journey

> 一套故事驱动的少儿编程进阶课程：**Scratch（接物 / 打地鼠游戏）→ Python（海龟画图 turtle / pygame 打砖块）→ AI（AI 对话 / AIGC）**。小机器人"码力"带孩子闯过三个战场，从"会动手"进化到"会创造"。

**Mali's Journey Home** — a story-driven coding curriculum for ages 7–14. Kids follow one little robot through Scratch games, Python turtle & pygame projects, and hands-on AI — every project is one chapter of the same journey home.

## 30 秒故事

> 地球被垃圾淹没，人类移居太空。小机器人**码力**被唤醒，程序里写着最后一个任务：**把地球打扫干净，接人类回家。**
>
> 他在地面学会分拣垃圾（Scratch），再造飞船清理太空轨道（Python），最后装上 AI 大脑**艾芯**（谐音"爱心"），用创造重建家园（AI）。孩子跟着码力走完这条路，就从"会动手"走到了"会创造"。

**体系闭环**：最后一站的 AI 会给「太空垃圾清理战」生成新关卡与素材——学 AI 的孩子反过来给学 Python 的孩子"供货"，五个项目不是散装作业，而是一个互相咬合的小世界。

## 为什么这样设计（三条线）

1. **工具难度阶梯**：积木（零语法门槛）→ 代码（语法与抽象）→ 模型（与 AI 协作）。每换一次工具，故事都给足理由：想上天，所以学 Python；不会创造，所以需要 AI。
2. **叙事因果链**：每个项目由上一个项目的"未完成"推动——地面清完才发现轨道垃圾，轨道疏通了才发现清空的大地需要创造。技能进阶和故事推进是同一条线：孩子不是"做练习"，是"救码力"。
3. **能力主线**：模仿搭建（会动手）→ 造与算（会思考）→ 创造（会表达）。

## 教学约定（每个项目都按这套来）

- **双 README**：学生版（孩子能懂：玩法 / 跟着做 / 挑战任务）+ 教师笔记（三维目标 / 卡点急救表 / 讲解话术 / 分层任务）——本仓库既是学生用的课程，也是教师可直接取用的教研材料。
- **单课时节奏（90 分钟）**：故事一拍 3′ → 目标演示 5′ → 跟做 40′ → 自主改造 20′ → 展示互评 15′ → 下站钩子 5′。
- **分层任务**：基础（跟做）→ 进阶（加功能）→ 挑战（做变体），快的孩子永远有事做。
- **情境教学**：每课开场 30 秒讲"码力此刻遇到的问题"，下课前留一个钩子，孩子带着期待等下一站。
